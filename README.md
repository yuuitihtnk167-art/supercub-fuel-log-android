# Supercub Fuel Log (Android)

Kotlin + Jetpack Compose で作り直した Android アプリです。  
給油記録・履歴・CSV入出力・月次レポートに対応しています。

## セットアップ

1. **Firebase プロジェクト作成**
   - Firestore を有効化
   - Authentication で **Google ログイン** を有効化
   - Android アプリを追加（パッケージ名: `com.yuu.supercubfuellog`）
   - `google-services.json` をダウンロードして `app/` に配置

2. **Web クライアント ID**
   - Googleログイン用のWeb OAuthクライアントを含む最新の `google-services.json` を配置
   - Google Servicesプラグインが生成する `R.string.default_web_client_id` を利用

3. **デバッグ用 SHA-1 の登録**
   - Firebase の Android アプリ設定で **SHA-1** を登録  
     （Android Studio の `gradle signingReport` で取得）

## 起動・ビルド

Android Studio で開いて実行してください。  
ターミナルでビルドする場合は、**先に `gradle wrapper` を実行**してから以下を使います。

```bash
./gradlew assembleDebug
```

生成された APK は以下に出力されます。

```
app/build/outputs/apk/debug/app-debug.apk
```

## 使い方

- Googleログイン必須。ログイン後、本人の `users/{uid}/records/{recordId}` を読み込みます。
- 記録・編集・削除・履歴・月次レポートはクラウド専用です。設定からログアウトできます。
- 設定画面の「データ管理」でCSVを選ぶと、有効件数・追加件数・重複件数・不正行数を確認してから取り込めます。
- 日付・走行距離・給油量が同じ行はスキップし、既存のクラウド記録は上書き・削除しません。
- 同じCSVを再度取り込んだ場合や、一部取込後の失敗を再試行した場合も、固定の取込IDで増殖を防ぎます。
- CSVエクスポートに対応。通信失敗時は入力・取込確認内容を保持します。同じ操作を再試行する前に再読み込みで結果を確認できます。

## データ管理

- 「設定」→「データ管理」でCSV入出力と「最新の記録に更新」を実行できます。
- 「CSVインポート」はクラウドへ取り込み、「記録をCSVに書き出す」はクラウドの記録をスマホなどの保存先へ書き出します。
- 履歴画面にはCSV操作を置かず、一覧・編集・削除・計算式の確認を残しています。
- 旧端末内記録の書き出しUIはありません。端末内に旧データベースが残っていても、この画面整理による削除や更新は行いません。

## 実機での確認

1. Googleログイン・承認確認後、「履歴」で一覧・編集・削除・計算式を確認する。
2. 「設定」→「データ管理」にCSVインポート、その下に最新記録への更新、CSV書き出しが表示されることを確認する。
3. テスト記録を1件保存し、再読み込み・アプリ再起動・同一アカウントでの再ログイン後も表示されることを確認する。
4. CSV取込前の件数確認、既存記録の保持、同じCSVの再取込で追加0件になることを確認する。
5. オフラインで保存を試し、失敗通知と入力保持を確認する。通信復旧後に同じ入力を再試行する。
6. ログアウト・別アカウントでログインし、前の履歴・入力・取込確認が表示されないことを確認する。

Firebase側のデータベース作成・ルール公開は別途確認が必要です。この実装はFirebase側の設定を変更しません。

## 利用承認（本番ルール未公開）

Google認証に加え、管理者が登録した `allowedUsers/{uid}` の `enabled: true` が必要です。
これはAuthenticationへの登録を防ぐものではなく、認証後の利用制限です。
自分のUIDを先に許可リストへ登録し、その後ルールを公開してください。
公開順序・取り消し・テスト手順は [許可リスト設定手順](docs/ALLOWLIST_SETUP.md)、公開用ルール全文は [firestore.rules](firestore.rules) を参照してください。
